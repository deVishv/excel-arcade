I got you covered

Learn Excel keyboard shortcuts and essential formulas by playing. 13 self checking practice workbooks with stages, XP, stars, boss fights, speedruns, and built in spaced repetition.

## Requirements
- Windows
- Microsoft Excel 365 or Excel 2021+

## Get started
1. Download the latest release from the [Excel Arcade Releases Page](https://github.com/deVishv/excel-arcade/releases/latest).
2. Open `01 Shortcuts 1 - Navigate and Select.xlsx` and start on the **Start** sheet.
3. Use `00 Review Deck.xlsx` for about 10 minutes a day to keep everything fresh.

## How to play
Each world has a **Start** hub, 3–5 **stages**, a **Boss** and a **Cheat Codes** sheet.
- **Stages:** read the *Briefing*, answer the *Warm-up* (reviews of earlier moves), the *Training* (pick from a list) and the *Challenges* (type the answer, then do it for real in the stage's **Arena** sheet).
- **Yellow cells are yours.** Type an answer, pick from a list with **Alt+↓**, or follow a **> ARENA** link.
- **Feedback:** `✔ CLEAR` right · `✘ TRY AGAIN` wrong · `· not yet` drill not done. For formatting and hiding drills, press **F9** to refresh the check.
- **Scoring:** 10 XP per question, or 5 XP if you pick *Show hint*. Stars: ★☆☆ at 50%, ★★☆ at 80%, ★★★ at 100%.
- **Boss:** unlocks when every stage has at least one star. Stamp START and FINISH with **Ctrl+Shift+:** to race the par time.
- **Rank:** S (100% and under par) · A ≥ 90% · B ≥ 75% · C ≥ 50% · D.
- **Replay a stage:** select a run of its yellow cells (Ctrl+click to add more), then press **Delete**.

## Spaced repetition
- **Inside the course:** every move comes back in later Warm-ups, Boss flashbacks and the Final Boss, at growing intervals.
- **Across days:** the Review Deck keeps each move in a box from 1 to 5. Box 1 comes back tomorrow; Box 5 waits a month (intervals of 1, 3, 7, 14 and 30 days). Answer the cards that are **DUE**, set each card to its suggested box, and stamp the date with **Ctrl+;**.

## Building the workbooks yourself (optional)
The workbooks are generated by Python from plain content files, and every check is verified in real Excel. You only need this to change content or contribute.
```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python -m excel_drills.build --out workbooks # all 13 workbooks
.venv/Scripts/python -m excel_drills.build --only S1 # one workbook (S1–S4, F1–F7, FINAL, DECK)
.venv/Scripts/python -m pytest -m "not excel" -q # fast static tests
.venv/Scripts/python -m pytest -m excel -q # real Excel (Windows + Excel, ~20 min)
```
Content is in `excel_drills/content/`. Workbooks are never edited by hand. Change the content and rebuild.
